# SafarNama — Explore · Dream · Discover
> **Award-Winning Luxury Travel Experience Platform**

SafarNama is a modern, high-performance web platform designed for luxury travel exploration, custom holiday planning, and interactive destination booking.

---

## 🌟 Key Features

1. **300-Frame Interactive Cinematic Canvas**:
   - High-speed GPU pre-decoded frame-by-frame scroll animation streaming via custom Vite dev middleware.

2. **Lenis Smooth Scroll & Adaptive Glassmorphism**:
   - Ultra-smooth momentum scroll engine synced with GPU-accelerated backdrop blur cards.

3. **Dynamic Interactive Destination Detail Modals**:
   - Photo gallery switchers, climate & seasonal weather badges, top attractions lists, and day-by-day sample itineraries for 11+ global destinations (**Kashmir**, **Bali**, **Ladakh**, **Kerala**, **Maldives**, **Cappadocia**, **Santorini**, **Kyoto**, **New York**, **Machu Picchu**, **Iceland**).

4. **Dedicated Package Reservation Flow**:
   - Direct destination booking integration with instant confirmation toast notifications.

5. **Tailor-Made Custom Trip Planner**:
   - Custom travel style, budget preference, and group sizing questionnaire modal.

6. **Strict Scroll Containment**:
   - Background body scroll locking and overscroll containment (`overscroll-behavior: contain`) for unhindered modal browsing.

---

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Styling**: TailwindCSS & Custom Glassmorphic Token System
- **Smooth Scroll**: Lenis Smooth Scroll Engine
- **Icons**: Lucide React
- **Build Tool**: Vite 6

---

## 🚀 Quick Start Guide

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build Production Bundle
```bash
npm run build
```
